# 🧠 Встань с дивана: Эволюция Скуфа

**Встань с дивана: Эволюция Скуфа** — браузерная physics drop-and-merge / clicker / roguelite игра для ПК и мобильных устройств.

Игрок сбрасывает мысли в стакан, объединяет одинаковые уровни, зарабатывает Мотивацию, прокачивает Скуфа и сражается с боссами. Главная цель — пройти цепочку эволюции от самых простых мыслей до **T10 Гигачада**.

## 🎮 Игровой цикл

1. Сбросить мысль в стакан.
2. Соединить две одинаковые мысли.
3. Получить мысль следующего тира.
4. Заработать Мотивацию и нанести урон боссу.
5. Следить за заполнением стакана и красной линией.
6. Победить босса до окончания таймера.
7. Выбрать реликвию и усилить текущий забег.
8. Покупать постоянные улучшения и двигаться дальше по эволюции.

В основной прогрессии находится **20 боссов**. После прохождения основной цепочки становится доступен бесконечный режим.

## 🧬 Эволюция мыслей

В игре используется цепочка из 10 тиров:

```text
T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9 → T10 Гигачад
```

Если две одинаковые мысли сталкиваются друг с другом, они объединяются в следующую.

Каждое успешное слияние:

- освобождает место в стакане;
- увеличивает ценность новой мысли;
- приносит Мотивацию;
- наносит урон текущему боссу;
- помогает строить более длинные merge-цепочки.

## 🧰 Расходники

Во время игры можно использовать специальные предметы, которые помогают справиться с неудачной раскладкой или ускорить прогресс.

### 🥤 Лимонад

Удаляет выбранную тревожную мысль или мусор с игрового поля.

### 📜 Скрипт

Автоматически объединяет подходящую пару одинаковых мыслей.

### ⚡ Флэш

На время замедляет физику и позволяет стабилизировать стакан.

### 💥 Петарда

Резко разбрасывает содержимое стакана и помогает разрушить плотный завал.

### 🧲 Магнит

Стягивает мысли ближе к центру и помогает подготовить новые слияния.

## 👹 Боссы

Каждый босс имеет собственный запас HP и может влиять на правила текущего этапа.

Встречаются эффекты, которые меняют:

- скорость восстановления Дыхалки;
- урон игрока;
- пассивный доход;
- частоту появления мусора;
- скорость ручного сброса;
- продолжительность таймеров;
- поведение физики;
- эффективность отдельных механик.

Это делает каждый следующий этап немного отличающимся от предыдущего.

## 🔥 Хайп / Fever

Хайп — временный усиленный режим.

Во время него игрок получает повышенную эффективность и может быстрее развивать цепочки слияний. Некоторые улучшения, реликвии и события дополнительно усиливают Fever или меняют его длительность.

## 🛋️ Прокачка

Развитие поделено на несколько направлений.

### Тело

Улучшения, связанные с Дыхалкой, активными действиями и эффективностью Скуфа.

### Берлога

Развитие комнаты и объектов, которые увеличивают пассивный доход и дают дополнительные игровые бонусы.

### Разум

Улучшения механик, связанных с игровым полем, слияниями и удобством прохождения.

### Карьера

Экономические улучшения, усиливающие доход и общую скорость прогрессии.

## 🌀 Сансара

Сансара — система долгосрочного перерождения.

Игрок может сбросить часть текущего прогресса ради получения постоянных бонусов. Это позволяет постепенно ускорять следующие прохождения и строить более сильные билды.

## 🕹️ Управление

### ПК

- **мышь / pointer** — выбрать позицию и сбросить мысль;
- **Space** — сбросить мысль;
- **двойной клик по стакану** — микро-подброс;
- **A / ←** — наклонить стакан влево;
- **D / →** — наклонить стакан вправо;
- **Z** — включить или выключить Автосброс;
- боковой HUD можно свернуть, чтобы освободить больше места под игровое поле.

### Телефон

- **тап** — выбрать позицию и сбросить мысль;
- **двойной тап** — микро-подброс;
- нижняя панель содержит Встряску, Автосброс, наклоны и гироскоп;
- верхний HUD можно свернуть;
- в компактном режиме остаются основные показатели текущего забега.

## 🚨 Красная линия

В верхней части стакана находится опасная зона.

Игра учитывает устойчивые физические тела, которые слишком долго находятся выше красной линии. Кратковременное попадание новой падающей мысли в эту область само по себе не должно мгновенно завершать игру.

Если стакан действительно переполнен и завал остаётся выше линии достаточно долго — наступает Game Over.

## 🚀 Локальный запуск

Установить зависимости:

```bash
npm install
```

Запустить локальный сервер:

```bash
npm run dev
```

После запуска открыть:

```text
http://localhost:3000
```

## 📦 Сборка

Для создания компактной production-сборки используется:

```bash
npm run build:zip
```

Основная клиентская версия игры находится в:

```text
index.html
css/
js/
```

Сервер разработки, зависимости и служебные файлы не требуются для запуска готовой статической версии игры.

## 💾 Сохранения

Игра поддерживает сохранение прогресса и восстановление состояния забега.

Сохраняются основные параметры прогрессии, улучшения, ресурсы, состояние текущего прохождения и другие важные игровые данные.

Также предусмотрена миграция между версиями сохранений, чтобы обновления игры не ломали уже существующий прогресс.

## 📱 Адаптивность

Интерфейс рассчитан как на большой экран, так и на мобильные устройства.

На ПК используется боковая компоновка HUD, а на телефоне интерфейс перестраивается в более компактный вертикальный формат. Панели можно сворачивать, чтобы основную часть экрана занимал стакан и физическое игровое поле.

## 🏆 Цель игры

Главная цель — пройти путь от первых мыслей до **Гигачада**, победить всех основных боссов и построить максимально сильный постоянный прогресс через улучшения и Сансару.

После этого игру можно продолжать в бесконечном режиме, улучшая рекорды и экспериментируя с разными сочетаниями усилений.
