# 🧠 Встань с дивана: Эволюция Скуфа

**Браузерный physics drop-and-merge / clicker / roguelite про Скуфа, который пытается пережить аренду, внутренние кризисы и 20 боссов, чтобы в итоге стать Гигачадом.**

Игра рассчитана на ПК и мобильные браузеры и использует адаптивный HUD: на ПК левую панель можно свернуть влево, на телефоне верхний HUD — вверх, чтобы освободить максимум места под стакан.

---

## 🎮 Основной цикл

1. Прицелиться и сбросить мысль в стакан.
2. Соединять две одинаковые мысли в следующий тир.
3. Получать Мотивацию за слияния и пассивный доход.
4. Не допускать переполнения стакана выше красной линии.
5. Побеждать босса до окончания таймера аренды.
6. Выбирать реликвии, покупать улучшения и переходить к следующему дню.
7. После длинных забегов использовать Сансару и получать Золотые Диваны для постоянных усилений.

---

## 🧬 Эволюция мыслей

В игре 10 основных тиров:

| Тир | Мысль |
|---:|---|
| T1 | 🐱 Квадробер |
| T2 | 🥺 Симп |
| T3 | 👓 Тюбик |
| T4 | 🧢 Зумер |
| T5 | 🎀 Альтушка |
| T6 | 🌹 Масик |
| T7 | 👴 Дед |
| T8 | 🍺 Скуф |
| T9 | 🗿 Сигма |
| T10 | 👑 Гигачад |

Одинаковые тела сталкиваются через Matter.js и объединяются физически. Размеры шаров автоматически масштабируются под доступную высоту стакана.

## 👹 Боссы, аренда и эффекты

В основной цепочке — **20 боссов** с растущим HP. Каждый день ограничен таймером аренды: если не успеть победить босса, забег заканчивается.

Кроме обычного HP у игры есть два отдельных слоя модификаторов:

- **Эффект дня** — ежедневный модификатор, меняющий правила текущей сессии.
- **Эффект босса** — собственная механическая особенность текущего босса.

Эти эффекты показываются компактными чипами в HUD, а подробное описание открывается по нажатию.

Боссы также используют активные атаки, включая землетрясения, мусор и испорченные мысли.

---

## 💎 Мотивация и Дыхалка

**Мотивация** — основная валюта игры. Она приходит:

- за слияния;
- от пассивного дохода;
- за квесты и события;
- от интерактивных объектов комнаты;
- из оффлайн-дохода;
- из некоторых наград и рекламных бустов.

На ПК и телефоне развёрнутый HUD показывает название **Мотивация**, текущее количество и автоматический доход в секунду. В свёрнутом игровом режиме остаётся компактная строка с ключевыми показателями.

**Дыхалка** расходуется на прямые тапы по Скуфу и восстанавливается со временем. Некоторые улучшения, события и взаимодействия с комнатой меняют её максимум и скорость восстановления.

## 🎒 Расходники

- 🍺 **Балтика** — растворяет выбранную мысль или мусор.
- 📜 **Скрипт** — помогает соединить одинаковые мысли.
- ⚡ **Флэш** — временно замедляет физику.
- 💣 **Петарда** — взрывает завал.
- 🧲 **Магнит** — стягивает мысли к центру.

---

## 🌀 Прокачка и Сансара

Обычная прокачка разделена на несколько направлений: тело, берлога, разум и карьера.

Сансара — prestige-система. Игрок сбрасывает текущий забег ради **Золотых Диванов**, которые тратятся на постоянные перки. Стоимость перков растёт по мере прокачки, поэтому первый prestige больше не позволяет почти мгновенно закрыть всю ветку.

## 🕹️ Управление

### ПК

- **Мышь / Pointer** — прицеливание и сброс мысли.
- **Клик по Скуфу** — прямой урон боссу за Дыхалку.
- **Двойной клик/тап по стакану** — микро-подброс тел; имеет отдельный кулдаун.
- **Space** — сбросить мысль.
- **A / ←** — наклонить стакан влево.
- **D / →** — наклонить стакан вправо.
- **Z** — включить или выключить автосброс.
- Кнопка на левом краю позволяет полностью свернуть левый HUD.

Базовый ручной сброс имеет заметный кулдаун; игровые улучшения и отдельные эффекты могут его ускорять.

### Телефон

- **Тап / pointer** — прицеливание и сброс.
- **Двойной тап** — микро-подброс с кулдауном.
- Нижняя панель — Встряска, Автосброс, наклон влево/вправо и гироскоп.
- Верхний HUD можно свернуть вверх. В свёрнутом состоянии остаётся компактная строка с ключевой информацией, а стакан получает почти всю высоту экрана.

## 📺 Яндекс Игры

Интеграция находится в `js/yandex.js`.

Используются:

- `YaGames.init()`;
- `LoadingAPI.ready()`;
- `GameplayAPI.start()` / `stop()`;
- `player.getData()` / `player.setData()` для облачного сохранения;
- Leaderboards API;
- rewarded video;
- fullscreen interstitial;
- sticky banner.

**Награда за rewarded video выдаётся только в `onRewarded`.** Закрытие или ошибка рекламы сами по себе награду не дают.

Для локальной разработки используется `dev/sdk-mock.js`. Рекомендуемый запуск — через `npm run dev`, где `server.js` отдаёт mock по пути `/sdk.js`.

В опубликованной версии для Яндекс Игр в `index.html` остаётся:

```html
<script src="/sdk.js"></script>
```

Отдельный production-файл `sdk.js` в корень проекта добавлять не нужно — на платформе этот путь предоставляет Яндекс.

### Release-архив

Для сборки ZIP, предназначенного для загрузки на сервер Яндекс Игр:

```bash
npm run build:zip
```

Команда создаёт `skuf-release.zip` только из `index.html`, `css/` и `js/`. Локальный mock, `server.js`, `package.json` и dev-файлы в игровой архив не входят.

## 🚀 Локальный запуск

```bash
git clone https://github.com/fyksikk/skuf.git
cd skuf
npm install
npm run dev
```

После запуска открыть:

```text
http://localhost:3000
```

Этот способ удобен для проверки UI и логики рекламных наград через локальный Yandex mock. Финальную работу реальной рекламы и платформенных событий нужно проверять уже в Draft/Prod окружении Яндекс Игр.
