# 🧠 Встань с дивана: Эволюция Скуфа

Браузерная physics drop-and-merge / clicker / roguelite игра для ПК и мобильных браузеров с интеграцией Яндекс Игр.

**Целевой возрастной рейтинг: 12+.** Пользовательские упоминания алкоголя заменены на нейтральные напитки. Внутренние legacy-id вроде `beer`, `brewery` и `relic_beer_shield` сохранены только ради совместимости старых сохранений.

## 🎮 Основной цикл

1. Сбросить мысль в стакан.
2. Соединить две одинаковые мысли в следующий тир.
3. Получить Мотивацию и нанести урон боссу.
4. Не держать устойчивые тела выше красной линии слишком долго.
5. Победить босса до окончания таймера.
6. Выбрать реликвию, прокачаться и перейти дальше.
7. После длинного забега использовать Сансару ради постоянных перков.

В основной цепочке 20 боссов, затем доступен endless-режим.

## 🧬 Системы

- 10 тиров мыслей: T1 → T10 Гигачад;
- Matter.js-физика и chain merge;
- Мотивация + пассивный доход/сек;
- Дыхалка и прямой урон тапами по Скуфу;
- ежедневные эффекты;
- индивидуальные эффекты боссов;
- активные атаки боссов;
- расходники: Лимонад, Скрипт, Флэш, Петарда, Магнит;
- Хайп / Fever;
- реликвии забега;
- прокачка Тела, Берлоги, Разума и Карьеры;
- Сансара / Золотые Диваны;
- ежедневные квесты;
- достижения;
- Колесо Фортуны;
- интерактивная комната;
- оффлайн-доход;
- локальное и облачное сохранение;
- лидерборд Яндекс Игр;
- rewarded / fullscreen / sticky ads.

## 🕹️ Управление

### ПК

- мышь / pointer — прицеливание и сброс;
- `Space` — сброс мысли;
- двойной клик по стакану — микро-подброс, отдельный кулдаун 4 секунды;
- `A` / `←` — наклон влево;
- `D` / `→` — наклон вправо;
- `Z` — Автосброс;
- левый HUD можно свернуть влево.

### Телефон

- тап — прицеливание и сброс;
- двойной тап — микро-подброс с кулдауном;
- нижняя панель — Встряска, Автосброс, наклоны и гироскоп;
- верхний HUD можно свернуть вверх;
- в свёрнутом режиме остаётся мини-HUD с Мотивацией, доходом/сек, HP босса, таймером и Дыхалкой.

## 📖 Правила внутри игры

Кнопка **«Как играть»** открывает актуальный гайд по финальной версии: управление, кулдауны, красная линия, Мотивация, Дыхалка, эффекты дня/босса, расходники, Fever, Сансара, меню, сворачивание HUD, реклама и сохранение.

## 📺 Яндекс Игры

В `index.html` используется:

```html
<script src="/sdk.js"></script>
```

Собственный production `sdk.js` в архив не добавляется.

Интеграция включает `YaGames.init()`, LoadingAPI, GameplayAPI, Player cloud save, Leaderboards API, rewarded video, fullscreen interstitial и sticky banner.

Rewarded-награда выдаётся только после `onRewarded`. Если реклама не загрузилась или была закрыта без награды, бонус не начисляется.

Локально SDK эмулируется через `dev/sdk-mock.js`.

## 📦 ZIP для Яндекс Игр

В production ZIP должны попасть **только**:

```text
index.html
css/
  style.css
js/
  matter.min.js
  config.js
  physics.js
  audio.js
  yandex.js
  room.js
  ui.js
  game.js
  polish.js
  polish-core.js
  final12.js
  hud.js
```

Не добавлять:

```text
dev/
server.js
package.json
package-lock.json
node_modules/
README.md
metadata.json
.git/
sdk.js
```

`index.html` должен лежать непосредственно в корне ZIP.

Если установлен `zip`, используйте:

```bash
npm run build:zip
```

Текущий script архивирует `index.html`, `css/` и `js/`, поэтому `polish-core.js` и `final12.js` попадут в релиз автоматически.
