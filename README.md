# 🧠 СКУФ В ГИГАЧАДА: Эволюция Мышления (Skuf to Gigachad)

> **Затягивающий физический кликер-рогалик в стиле Suika Game с механикой эволюции, менеджментом ресурсов, боссами, престижем и юмором.**

Помоги легендарному Скуфу преодолеть лень, оплатить растущую аренду, победить 20 внутренних боссов (от Прокрастинации и Думскроллинга до Финального Босса Лени) и эволюционировать в несокрушимого Сигма-Гигачада!

---

## 🎮 Особенности игры

- **Физический стакан мыслей на Matter.js:**
  - Объединяйте одинаковые мысли по законам физики (от пива и чипсов до квантового кода и абсолютного разума).
  - Адаптивный стакан под любые экраны смартфонов и мониторов ПК с защитой от вылета предметов за пределы поля.
- **Динамическая подгонка фото (Aspect-Ratio Cover):**
  - Фотографии персонажей любого разрешения и формата идеально помещаются внутри шаров с красивой цветной рамкой и без искажения пропорций.
- **Прокачка и интерьер комнаты из реальных материалов:**
  - Настоящая материальная визуализация: литые шестигранные чугунные гантели с хромированным грифом, стальная мини-пивоварня с латунным краном и манометром, крафтовая коробка пиццы, пушистый спящий кот на подлокотнике дивана и RGB-сетап.
- **Полная интеграция с Яндекс Играми (Yandex Games SDK):**
  - Таблица лидеров (Leaderboard): автоматическая синхронизация рекордов мотивации среди всех игроков и отображение топ-15.
  - Рекламные бусты (Rewarded Ads): Турбо-Хайп, Генеральный Клининг, Крипто-Дроп и Ядерная Петарда с безопасным начислением наград.
  - Полноэкранная межстраничная реклама с защитой от спама.
- **Векторная графика мыслей и тревог (Без устаревших эмодзи):**
  - 100% чёткий векторный рендеринг персонажей, тревожных мыслей и мусора (сомнения, долги, бессонница, синдром самозванца, думскроллинг, выгорание).
  - Детальные светящиеся иконки с высоким DPI, неоновыми аурами и гарантированной отрисовкой на всех мобильных устройствах и ПК.
- **Сбалансированная Лихорадка (Fever Mode):**
  - Ограниченный и честный урон по боссам во время комбо-хайпа (увеличение очков x3 и ускорение сброса без мгновенного убийства боссов).
- **Пружинистая физика на Matter.js:**
  - Настроенная гравитация и повышенная упругость шаров (restitution), обеспечивающие сочные пружинящие столкновения и микро-подбросы.
- **Разгруженный и эргономичный UI/UX:**
  - Компактный верхний HUD без нагромождений текста и наездов элементов.
  - Удобная навигация, читаемые бейджи и кнопки с защитой от случайных кликов.
- **Масштабируемые числа (K, M, B, T, Qa, Qi ... DDc):**
  - Поддержка огромных чисел с красивыми буквенными суффиксами вплоть до дуодециллионов.
- **Переключатель спецэффектов (FX Режим):**
  - Мгновенное отключение тяжёлых эффектов свечения, теней и частиц для плавной работы 60 FPS на слабых смартфонах и ПК.
- **Жёсткий рогалик (Выселение на улицу):**
  - Не успел оплатить аренду вовремя или переполнил стакан мыслей? Тебя выселяют на улицу с полным сбросом забега!
- **Сансара / Престиж:**
  - Накапливай гены Гигачада и перерождайся с постоянными перками (генная модификация, золотой стакан, скидки).
- **Расходники:**
  - 🍺 Балтика: растворяет любой шар или мусор кликом.
  - 📜 Скрипт: стягивает две одинаковые мысли воедино.
  - ⚡ Флэш: замедляет время на 10 секунд.
  - 💣 Петарда: точечно взрывает завалы.
  - 🧲 Сигма-Магнит: собирает парные мысли по всему стакану.

## 🕹️ Управление

- **Мышь / Сенсорный экран:**
  - Перемещение пальцем или курсором по экрану — прицеливание сброса мысли.
  - Отпускание / клик — сброс мысли в стакан.
- **Горячие клавиши (ПК):**
  - `Пробел` — сбросить мысль.
  - `S` — Встряска мозга (перемешать застрявшие мысли).
  - `1` — Использовать Балтику.
  - `2` — Использовать Скрипт.
  - `3` — Использовать Энергетик Флэш.
  - `4` — Взорвать Петарду.
  - `5` — Активировать Магнит.
  - `M` — Вкл/Выкл звук.

## 🚀 Установка и запуск

Проект написан на чистом **JavaScript (ES6+)** и работает в любом современном браузере.

### Локальный запуск через Node.js:

```bash
# Установка зависимостей (при необходимости)
npm install

# Запуск локального сервера разработки
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Статический запуск:
Можно открыть файл `index.html` напрямую через Live Server в VS Code или любой HTTP-сервер (Nginx, Caddy, Python `python3 -m http.server 3000`).

## 🛠️ Стек технологий

- **HTML5 Canvas** — Высокопроизводительный 2D рендеринг игрового поля и комнаты.
- **Matter.js** — 2D физика твёрдых тел, расчёт импульсов, упругости и столкновений.
- **Web Audio API** — Процедурный синтез звуков без необходимости подгружать тяжёлые аудиофайлы.
- **CSS Grid / Flexbox** — Адаптивная вёрстка под экраны любых диагоналей и ориентаций.
