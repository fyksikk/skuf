# 🧠 ВСТАНЬ С ДИВАНА: Эволюция Скуфа
> **Затягивающий физический дроп-мердж, кликер и рогалик-симулятор превозмогания бытия.**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Помоги легендарному Скуфу преодолеть лень, оплатить растущую аренду, победить 20 внутренних боссов (от Хозяйки Тамары и Депрессии до Владыки Судьбы) и эволюционировать в несокрушимого **👑 ГИГАЧАДА**!

---

## 🎮 Особенности игры

- **Физический стакан мыслей (Matter.js):** Сбрасывайте и объединяйте одинаковые мысли по законам физики. Адаптивный "череп" подстраивается под любые экраны смартфонов и ПК.
- **10 Уровней Эволюции:** От милого 🐱 *Квадробера* до легендарного 👑 *ГИГАЧАДА*. Каждый тир имеет уникальный радиус, цвет, свечение и награду.
- **Система Боссов и Аренды:** Каждый "день" (уровень) появляется новый босс с уникальной цитатой и растущим HP. Не успеете нанести урон до конца таймера аренды? **Выселение на улицу (Game Over)!**
- **Дыхалка (Stamina):** Прямые клики по Скуфу наносят урон боссу, но тратят выносливость. Следите за шкалой, чтобы не получить одышку!
- **Мусорные мысли:** В стакан падают опасные препятствия (*Кредит, Бывшая, Лень, Дедлайн, Бессонница, Тревога, Похмелье, Прокрастинация*). Они не сливаются, но могут быть уничтожены мощными слияниями или расходниками.
- **Глубокая система прокачки (4 ветки):**
  - 🦾 **ТЕЛО:** Урон клика, критические удары, скорость восстановления дыхалки.
  - 🏠 **БЕРЛОГА:** Пассивный доход и визуальная эволюция комнаты (от Хрущёвки с ковром до Орбитальной Сферы Дайсона).
  - 🧠 **РАЗУМ:** Расширение стакана, скорость сброса, снижение частоты мусора, усиление комбо.
  - 💼 **КАРЬЕРА:** Пассивный доход (Стрим, Крипта, Инфобизнес, IT-стартап, Выкуп дома у Тамары).
- **Реликвии забега:** При победе над боссом выбирайте 1 из 12 уникальных перков (например, *Пивной щит*, *Нейро-магнит* или *Цепной взрыв*).
- **Сансара (Престиж):** Сбросьте прогресс забега ради **Золотых Диванов**, дающих постоянные глобальные бонусы (генетическая база, старт с высоких тиров, оффлайн-доход).
- **Процедурный звук (Web Audio API):** Все звуки (слияния, клики, взрывы, фанфары) генерируются кодом в реальном времени. Никаких тяжёлых аудиофайлов!
- **Интерактивная комната:** Отрисовка на Canvas с деталями: чугунные гантели, мини-пивоварня, спящий кот, RGB-подсветка и переключаемые ТВ-каналы с баффами.
- **Полная интеграция с Yandex Games SDK:** Таблица лидеров, оффлайн-доход и рекламные бусты (Турбо-Хайп, Генеральный Клининг, Крипто-Дроп).

## 🎒 Расходники

- 🍺 **Балтика:** Растворяет любой выбранный шар или мусор одним кликом.
- 📜 **Скрипт:** Мгновенно притягивает и объединяет две одинаковые мысли на поле.
- ⚡ **Флэш:** Замедляет время падения мыслей на 10 секунд.
- 💣 **Петарда:** Взрывает и раскидывает опасный завал из мусорных мыслей.
- 🧲 **Сигма-Магнит:** Стягивает все парные мысли к центру стакана для легкого слияния.

## 🕹️ Управление

### 💻 ПК (Клавиатура и Мышь)
- **Мышь:** Наведение для прицеливания, клик для сброса мысли.
- **Клик по Скуфу:** Нанесение урона боссу (тратит Дыхалку).
- **`Пробел`**: Сбросить мысль.
- **`S`**: Встряска мозга (растолкать застрявшие мысли).
- **`A` / `D`** или **`←` / `→`**: Наклонить стакан влево/вправо.
- **`1` - `5`**: Быстрое использование расходников (Балтика, Скрипт, Флэш, Петарда, Магнит).
- **`M`**: Включить / выключить звук.

### 📱 Мобильные устройства
- **Тач:** Перетаскивание для прицеливания, отпускание для сброса.
- **Кнопки на экране:** Встряска, наклон стакана, включение гироскопа для управления наклоном устройства.

## 🚀 Установка и запуск

Проект написан на чистом **JavaScript (ES6+)** и не требует сложных систем сборки.

### Локальный запуск через Node.js / Bun:
```bash
# 1. Клонирование репозитория
git clone https://github.com/fyksikk/skuf.git
cd skuf

# 2. Установка зависимостей (Express для локального сервера)
npm install
# или bun install

# 3. Запуск сервера разработки
npm run dev
# или bun run dev
```
Откройте в браузере: `http://localhost:3000`

### Статический запуск:
Можно открыть файл `index.html` напрямую через расширение **Live Server** в VS Code или любой другой HTTP-сервер:
```bash
python3 -m http.server 3000
```

## 🛠️ Стек технологий

- **HTML5 Canvas:** Высокопроизводительный 2D-рендеринг игрового поля и комнаты.
- **Matter.js:** Продвинутая 2D-физика твёрдых тел (импульсы, упругость, трение, коллизии).
- **Web Audio API:** Процедурная генерация звуковых эффектов (осцилляторы, огибающие) без загрузки аудиофайлов.
- **Vanilla JS (ES6 Modules):** Чистый, модульный код без тяжёлых фреймворков.
- **CSS Grid / Flexbox:** Полностью адаптивная вёрстка под любые диагонали и ориентации экранов.
